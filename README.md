# eCOPY — 专业拷卡软件

[English](./README_EN.md) | 简体中文

**eCOPY — Professional Camera-Card Offload.** 多目标校验拷贝 · Safe to Format · 可审计报告

eCOPY 是一款面向影视拍摄现场的专业拷卡（Offload）软件：把摄影机卡的内容同时拷贝到多个目标盘，并对每个目标进行**独立回读校验**，全部通过后才给出「Safe to Format」信号，从流程上杜绝数据事故。

## 核心特性

### 数据安全
- **源卡全程只读** — 任何情况下都不会向源卡写入数据
- **独立回读校验** — 校验不依赖写入时的哈希，而是从每个目标盘重新完整读回、逐一比对（xxHash64）
- **Safe to Format 信任信号** — 只有当所有目标全部校验通过，界面才会显示绿色「SAFE TO FORMAT」；任一字节被篡改都会被检出并转为红色告警
- **增量恢复** — 任务中断后可恢复/重试，已校验文件保留，仅重新拷贝失败的部分；恢复后依然完整重新校验

### 工作流
- **三步向导** — 选源卡 → 选目标与模板 → 确认开始
- **多目标并发** — 同时写入多个目标盘，每条腿（Leg）独立进度、速度与状态
- **目录模板** — `{project} · {date} · {camera} · {reel} · {operator} · {volume} · {scene}` 变量，默认按 `项目/日期/机位/卷号` 组织
- **自动识别摄影机卡** — 外置卡插入即自动检测，识别 ARRI / RED / Sony / Blackmagic / Canon / Panasonic 等品牌、卡型与卷号
- **按拍摄日期筛选** — 卡内含多日素材时，可按拍摄日期（取自素材名，回退文件日期）勾选要拷贝的日期，统计实时更新
- **冲突策略** — 目标同名文件默认「失败并警告（最安全）」，也可选「两者保留、新文件重命名」
- **历史任务管理** — 全部拷卡记录可追溯，支持单条删除与一键清空（运行中的任务受保护不可删）

### 报告与审计
- 每个目标自动生成 **ASC MHL**（媒体哈希清单）、**CSV**、**HTML** 三种报告
- 记录校验值、路径、操作员、时间线，满足片场交付与审计要求
- 支持安全弹出（Eject）与「允许格式化」确认流

### 系统监控
- 磁盘卷列表、剩余空间、物理盘健康（SMART）
- SMART 温度监控（Windows 需管理员权限，应用内一键提权重启）

### 界面体验
- 深蓝「机场自助终端」风格 UI，开屏系统自检动画
- 拷卡时呈现**列车行驶动画**：起步加速、世界随拷贝速度流动、到站减速，视觉速度与真实拷贝速度成正比
- 全局动态氛围背景、右上角信息气泡、三语界面（中文 / 日本語 / English）

## 技术架构

```
┌─────────────────────────────────────────────┐
│  Electron Shell (electron/main.cjs)         │
│    ├─ 零依赖后端  src/backend/server.js      │  ← 端口 5218
│    │    ├─ engine.js    拷贝/校验引擎        │
│    │    ├─ checksum.js  xxHash64            │
│    │    ├─ reports.js   ASC MHL / CSV / HTML│
│    │    ├─ disks.js     卷 / SMART / 弹出    │
│    │    ├─ cameras.js   卡型识别            │
│    │    └─ store.js     任务持久化 (JSON)    │
│    └─ 原生前端    public/ (vanilla JS + SSE) │
└─────────────────────────────────────────────┘
```

- **后端**：Node.js（≥ 18.15）ESM，**零 npm 依赖**——所有拷贝、哈希、报告、SSE 均用原生模块实现
- **前端**：无框架原 生 JS，SSE 实时推送进度/日志/事件
- **打包**：electron-builder → Windows NSIS 安装版 + 便携版

## 快速开始

### 源码运行

```bash
npm install
npm start          # 后端 + Web UI → http://localhost:5218
npm run electron   # 以 Electron 桌面应用运行
```

### 构建 Windows 安装包

```bash
npm run dist       # 产物输出到 dist/：Setup 安装版 + 便携版
```

### 自检

```bash
npm test           # scripts/selftest.js
```

## 使用流程

1. **新建拷卡** — 插入摄影机卡后自动检测，选择源卡
2. **选择目标盘与目录模板**，填写项目名 / 操作员
3. **开始校验拷卡** — 拷贝阶段占进度 0–92%，回读校验占 92–100%；到达 100% 且全绿后方可格式化源卡

> ⚠️ 好习惯：格式化请在摄影机内进行。eCOPY 的「Safe to Format」表示数据已安全落在所有目标盘上。
